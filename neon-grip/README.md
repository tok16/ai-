# 🎮 Neon Grip: Протокол «Хват»

Мобильный top-down twin-stick bullet-hell roguelite на **Kotlin + LibGDX + Fleks (ECS)**.
Фишка: управление строится на **«философии 3 пальцев»** — два больших пальца ведут
плавающие стики (движение / прицел+автоогонь), а указательный палец правой руки лежит
на верхней грани телефона как консольный триггер L1/R1 и отвечает за рывок-«Фазовый
Сдвиг», ульту и тактическую перезарядку. Стреляй и маневри simultaneously.

## Модули
* `:core` — игровая логика: ECS-мир, системы, grip-контроллер мультитача, корутина-AI,
  object pools (500 пуль ×2, 2000 частиц), StateFlow-стейт, мета-прогрессия.
* `:android` — Activity: SurfaceView (LibGDX backend), immersive sticky (блокировка
  системных жестов), Edge-to-Edge + Safe Area через WindowInsets, строго landscape.

## Быстрый старт
```bash
./gradlew :core:test              # unit-тесты боевой экономики и пулов
./gradlew :android:assembleDebug  # APK
adb install -r android/build/outputs/apk/debug/android-debug.apk
```

Документация геймплея и архитектуры: [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md)

## Схема хвата
```
        ┌───────────────────────────────┐
  ═══   │  [триггер-зона ▮▮▮]           │   ← указательный ПРАВОЙ: рывок/ульта/перезарядка
        │                               │      (зона сдвинута на 12% внутрь — нет miss-input)
        │   ◉ плавающий стик      ◉ стик│
        │     движения (ЛЕВЫЙ)   прицела│   ← большие пальцы; левый стик рождается
        │                       +огонь  │      там, где впервые коснулись
        └───────────────────────────────┘
                  Landscape only
```
